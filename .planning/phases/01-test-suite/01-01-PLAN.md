## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Upstream Catch2 release -> local vendored files | Third-party source code downloaded at vendor time and committed to the repo. Compromised download surface. |
| Test code -> filesystem temp directory | Test writes `.rc` files to a shared temp directory; other processes on the CI runner could theoretically race on the path. |
| Test binary -> solver subprocess | `acousticsTests` invokes `acousticsMain` via a shell command built from controlled (test-literal) values. No user input flows in. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-01 | Tampering | Vendored Catch2 files (Task 1) | mitigate | Task 1 verifies the downloaded file starts with `// Catch v3.14.0` and has > 5000 lines, rejecting HTML error pages or truncated downloads. Files are committed verbatim to the repo — any future tampering would appear in `git diff`. Full GPG signature verification against Catch2's published `.asc` is out-of-scope for Phase 1 (available Phase 2+ if supply-chain hardening is requested). |
| T-1-02 | Tampering | Temp `.rc` file creation in `runAndGetNorm` (Task 2) | mitigate | Task 2 uses `mkstemp()` (not `tmpnam` or a fixed path) to create a unique temp filename atomically, preventing a TOCTOU race where a malicious process pre-creates a symlink at a predictable path. The file is removed immediately after the test run. |
| T-1-03 | Injection | Shell command built in `runAndGetNorm` (Task 2) | accept | The command string concatenates the mkstemp-produced rc path (known-safe: `/tmp/tmp.XXXXXX` with no shell metacharacters) and the `DACOUSTICS` compile-time macro (known-safe: absolute path to the solver directory). No runtime user input flows in. Accept. |
| T-1-04 | Denial of Service | `acousticsTests` hanging on a stuck subprocess | accept | If `acousticsMain` hangs, `popen`/`pclose` blocks indefinitely. Phase 1 accepts this — CI has a 6-hour job timeout, and the existing Python `make test` has the same exposure. No timeout harness added in Phase 1. Phase 2+ can add a watchdog if needed. |
| T-1-05 | Information Disclosure | Test output leaking paths/secrets in CI logs | accept | Output contains `LIBP_DIR` absolute paths (already present in existing `acousticsMain` stdout) and test temp file paths. No secrets. CI logs are public for PRs. Accept. |
